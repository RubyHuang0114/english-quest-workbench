# LEVEL UP 七上英语复习工作台

围绕用户提供的七上英语资料构建，默认范围为 Starter—Unit 3、原表不规则动词、现在完成时与过去完成时判断。Unit 3 职业、物主代词、名词所有格内容均标记为 `unit3`，可单独筛选，也参加混合训练。

## 使用

直接打开 index.html，或访问 GitHub Pages。无需安装依赖、登录账号或上传孩子的学习记录。电脑、手机浏览器均可用；建议电脑横屏或手机竖屏。

推荐每天：12题混合 → 看能力建议 → 8题薄弱专项 → 次日回访到期错题。

支持：专项筛选、七维混合、拼写/填空/选择/判断/听写/限定结构翻译、真题短语段探案及配套语法、逐题反馈、证据关联语音和花字奖励、间隔错题修复、动态能力建议、进度与报告导出、题包扩展。

## 内容说明

- 943道训练题（原669题＋unit3新增128题＋原补全对话专项42题＋押题04原题104空），102项动词（含同形不同义项目及无分词情态动词）。
- 91个精选目标词（unit3新增24个），另有28道短语应用题；不是完整课本词表。
- 14个主题与考点改编短语段，依据黄浦、杨浦、世外期中卷及课本视听文本，各配一道上下文语法题（unit3新增4组）。明确标识改编，不冒充原题。
- 21段 Starter / Unit 1 / Unit 2 / Unit 3 原声音频；听写采用浏览器合成语音，不冒充课本音频切片。
- 校正 bear 的 borne/born、lie（撒谎）的规则变化、read 的读音及情态动词无过去分词等问题。
- 过去完成时为用户明确要求的补充。判断先看参照时间和动作关系，不机械套用 before、already。

## 数据与评估

学习记录保存在当前设备的浏览器 localStorage，不含跨设备自动同步。手机和电脑访问同一网址仍各自保存；可通过「导出/导入进度备份」迁移，备份包含本机新增题包。导入替换当前档案，建议先备份。

每维最近20次作答，独立权重1、提示权重0.5。阅读和补全对话选句要求选项和证据关联同时成立才算完整正确；另列证据链完整率。至少5道不同题且5次独立作答，才提供表现分层。该评估用于训练建议，不是标准化测评或分数预测。

错题：答错或证据链有误即归档。之后新一组独立答对一次，1天后再查；到期再次独立正确才标记已修复。提示作答、同组重复、提前复查不增加修复次数。

翻译采用限定结构参考答案匹配及常见缩写规范化，不能穷尽所有正确表达。未匹配的合理表达可标记复核，保留错题和统计透明性；不会伪装成语言模型智能批改。

浏览器语音依赖设备的中文/英语语音包和媒体策略；可开关奖励语音，主动发音按钮保持可用。课本原声不依赖语音合成。

## 发布

GitHub Pages 从 main 分支根目录部署。运行时不需要密钥。仓库只包含工作台程序、经整理的题库、来源名称和选定原声，不包含原始试卷DOCX/PDF、完整抽取语料、本机路径或孩子的学习档案。

模块化文件：index.html 入口；style.css 响应式样式；app.js 交互与评估；data.js 基础题库；content.js 扩展包校验与加载；modules/catalog.js 正式单元目录。

## 英文连击奖励

答对按连击递进：Nice / Good / Very good / Excellent / Perfect / Wonderful / Amazing；同时配合 First Blood / Double Kill / Triple Kill / Quadra Kill / Penta Kill / Unstoppable / Legendary。答错中断连击；证据与关联正确但答案错误时，仅给思路奖励，不假报连击。

rewards.js 独立管理 Web Audio 街机音阶、英文高音调短句播报、手机音频唤醒与取消。采用系统英文语音（优先较自然的英语嗓音），不是特定游戏原声或特定角色配音；设备音色可能不同。设置页可试听1—5连击，并随时停止。换题和关闭奖励会取消尚未结束的奖励音。

新增检查：`node verify_rewards.cjs`。

## 押题04原题写句专项

用户补充的原题版、解析版共21篇104空：基础5篇23空，进阶5篇24空，综合11篇57空。目录20篇与正文21篇差异按正文处理。保留原题画线、提示、答案及原解析，未列年份地区，不冒充某地某年真题。故宫题原题版缺失的开场两句依据解析版补齐并注记。统一标为U1–U3综合（含unit3），可自主选择层级、整篇逐空或本层随机训练。自由写句按参考表达匹配，原文括号可选部分展开、斜杠备选句补全；不宣称穷尽所有合理表达，可标记待复核。少数原资料衔接或标点问题保留原文，并在解析旁说明。
